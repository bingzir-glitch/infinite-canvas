# 服装模特图鉴

在画布底栏的「扩展节点与工具」添加「服装模特图鉴」节点，浏览 4200+ 张 AI 服装与模特参考：写实服装 1407 套、动漫服装 1320 套、AI 模特 1499 位。

数据来自 [nvzhuang](https://github.com/paipiange/nvzhuang)（MIT 授权），展示图为 webp（缩略图 + 展示大图），数据清单随插件内置；图片走同站 `/nvzhuang/` 镜像优先，缺失自动回落上游 CDN。

## 用法

- **切库**：顶部三个页签切换写实服装 / 动漫服装 / AI 模特。
- **搜索**：搜索框支持中文关键词（如`连衣裙`，写实库）、英文关键词（如 `dress`）、编号（如 `SPR-0001`）和分类。
- **筛选**：分类下拉框（季节 / 内衣 / 泳装…，模特库为发型）。
- **插入画布**：点缩略图进入详情，看展示大图。
    - 点「插入画布」→ 落成一张原生图片节点，可继续喂给下游生图或连线。
    - 点「插入本页」→ 把当前列表页的图片横排一行插入。
    - 插入位置自动避让已有节点，不会叠图。
    - 插入的图片存进画布本地存储，之后离线也能看、能当生图参考。
- **原图**：动漫库与模特库提供原作者站点的原寸大图直链（详情页「原寸」按钮，新窗口打开）；写实库原寸 PNG 未公开，只有展示图。

## 说明

部署站如果自带 `/nvzhuang/` 全量镜像目录（data/ 与 assets/ 与插件 data/ 路径一致），插件优先走同站地址，不再经过 CDN；没有镜像的站自动回落 CDN，不影响使用。

图片版权归原作者所有（nvzhuang 按 MIT 授权；中文关键词翻译取自 ai-ref-library-cn 整理，仅作检索用），本插件只做浏览与引用；代码按仓库 LICENSE 授权。

## 数据再生

插件 `data/*.json` 由 `nvzhuang` 上游 `data*.js` 转换而来（转 JSON + 拼中文词），脚本见运维留档；上游更新后重跑脚本、替换镜像目录与插件 data 即可。
