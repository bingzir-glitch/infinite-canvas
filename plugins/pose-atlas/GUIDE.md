# 姿态图鉴

在画布底栏的「扩展节点与工具」添加「姿态图鉴」节点，浏览 [RuiC-PoseAtlas](https://github.com/HRuiCcc/RuiC-PoseAtlas) 的 288 组人体姿态 × 5 视角线稿。

## 用法

- **搜索**：顶部搜索框支持中文 / 英文 / 日文名称、编号（如 `P001`）、分类和系列。
- **筛选**：系列标签（性感全身 / 标准全身 / 上半身 / 双人）可叠加分类下拉框。
- **插入画布**：点缩略图进入详情，看该姿态的 5 个视角（正面 / 斜侧 / 侧面 / 俯视 / 仰视）。
    - 点任一视角 → 落成一张原生图片节点，可继续喂给下游生图或连线。
    - 点「整组插入」→ 5 个视角横排一行。
    - 插入位置自动避让已有节点，不会叠图。
    - 打开详情页时 5 张原图会在后台提前拉到本地，点插入直接用缓存，不用再等下载；插入的图片存进画布本地存储，之后离线也能看、能当生图参考。
- **下载原图**：详情页缩略图右上角 `↓`，下载 900×1200 PNG。

## 说明

素材取自上游静态站，jsDelivr 为主源、GitHub Pages 为备源。单张图片按「同站镜像 → jsDelivr → GitHub Pages」逐源自动切换：某个源 403/超时/内容异常时自动换下一个，全挂才显示可点击重试的占位。插入画布时原图会存进本地图片库（之后离线也能看、能当生图参考）；长期留存请用下载按钮保存原图 PNG。

部署站如果自带 `/pose-atlas/` 全量镜像目录（data/、img/、thumbs/ 与上游同结构），插件会自动优先走同站地址，不再经过 CDN；没有镜像的站会自动回落 CDN，不影响使用。
